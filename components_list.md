
# Components Required
## Soldier Monitoring System Using LoRa

| Sl. No. | Component | Purpose |
|---|---|---|
| 1 | ESP32 Development Board | Controls the system |
| 2 | LoRa SX1278 Module | Wireless data transmission |
| 3 | NEO-6M GPS Module | Obtains geographical location |
| 4 | Heart Rate Sensor | Reads pulse signals |
| 5 | Push Button | Emergency SOS input |
| 6 | Breadboard | Circuit prototyping |
| 7 | Jumper Wires | Component connections |
| 8 | USB Cable | Programming ESP32 |
| 9 | Compatible Power Supply | Powers the circuit |
| 10 | LoRa Antenna | Supports wireless communication |

## Software Requirements
- Arduino IDE
- ESP32 Board Package
- LoRa Library
- TinyGPSPlus Library

## Note
Actual components and connections depend on the prototype design. Verify voltage and pin requirements before connecting hardware.

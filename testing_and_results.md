
# Testing and Results
## Soldier Monitoring System Using LoRa

### 1. ESP32 Testing
Check whether the ESP32 board powers on and runs the uploaded program.

### 2. GPS Module Testing
Check whether the GPS module receives satellite signals and provides valid latitude and longitude.

### 3. Heart Rate Sensor Testing
Check whether the sensor produces pulse readings when used according to its instructions.

### 4. LoRa Communication Testing
Send a test message from the transmitter and check whether the receiver receives it.

### 5. SOS Button Testing
Press the SOS button and verify whether the programmed emergency message reaches the base station.

### 6. Base Station Testing
Verify that the receiver displays the data it actually receives.

### Expected Results
- GPS coordinates are obtained when a valid GPS fix is available.
- Sensor readings are collected by the ESP32.
- LoRa test messages are received by the base station.
- An emergency message is transmitted when the SOS feature is correctly implemented.
